# Quadra

Prototipo cliccabile di un CAF online, pensato per il telefono. "Quadra" è un nome provvisorio.

## Cosa contiene

- **Vista cliente**: percorsi guidati (prima dichiarazione 730, partita IVA forfettaria, famiglia con ISEE e bonus), caricamento documenti, stato della pratica, messaggi, agenda e videochiamata.
- **Vista operatore**: coda delle pratiche, controllo dei documenti, note interne, visto di conformità, gestione del team e report.

## Come provarlo

Apri `index.html` in un browser. È un unico file HTML, senza build né dipendenze da installare (i font arrivano da Google Fonts).

## Limiti

- È una demo: accesso, firma, pagamenti e videochiamata sono simulati.
- I dati sono finti e non esiste un backend.
- Prezzi, scadenze e liste dei documenti sono esempi, da validare con un professionista abilitato.
